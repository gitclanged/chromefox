# Runbooks

Step-by-step procedures. A runbook must be followable by someone who has never done the task,
and must be updated whenever reality differs from what it says.

| Runbook | When | Status |
| --- | --- | --- |
| [build-locally.md](build-locally.md) | Setting up a build machine; building | Outline — completed in Phase 1 |
| [upstream-update.md](upstream-update.md) | Mozilla releases a new ESR version | Outline — exercised in Phase 3 |
| [security-release.md](security-release.md) | Mozilla ships security fixes | Outline — exercised in Phase 3 |
| [release.md](release.md) | Publishing a Chromefox release | Outline — completed in Phase 6 |

Each runbook ends with a **log** table. Every time it's used, add a row: date, who, how long,
what went wrong, what was changed in the runbook.
