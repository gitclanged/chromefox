# Devlog

One file per working session, written **for the owner**: what was done, why, how it connects
to the rest of the project, and what was learned. It's the project's memory and your
learning journal.

- File name: `YYYY-MM-DD-<topic>.md` (add `-2`, `-3` for several sessions on one day).
- Template: [TEMPLATE.md](TEMPLATE.md). The `/end-session` skill fills it in.
- Never edit old entries except to fix factual errors; add a new entry instead.
