# Reviews

Reports from Gemini audits, upstream impact reports, design second opinions, and any external
review. File name: `YYYY-MM-DD-<topic>.md`. Prompts are in `docs/AI-TEAM.md`.

## Triage

Every report ends with a triage table filled in by Claude and approved by the owner:

| Finding | Severity | Decision | Task / issue / reason |
| --- | --- | --- | --- |
| 1 | blocker / should-fix / consider | fix / defer / won't fix | P?-?? or #issue or "because…" |

A report with no triage table is not finished.

Ideas from a report's "Better options" section are triaged too: the ones worth deciding
become rows under "Proposals" in [OPEN-QUESTIONS.md](../OPEN-QUESTIONS.md) (AGENTS.md
section 9).
